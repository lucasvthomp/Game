# Marcamar homepage media

`marcamar-hero-boat.mp4` is a compressed 720p copy of the free-to-use Pexels clip [People are boarding a boat at a dock](https://www.pexels.com/video/people-are-boarding-a-boat-at-a-dock-19321988/) by Sururi Ballıdağ. The file is encoded forward and then in reverse so its first and last scenes match for a smoother loop. It is used as the muted, looping homepage hero background in `client/src/pages/Home.tsx`.

The editorial section below the hero uses free-to-use Pexels stills:

- [Small Boat Docked Near Urban Harbor Area](https://www.pexels.com/photo/small-boat-docked-near-urban-harbor-area-34874656/)
- [Passengers in a Ferry](https://www.pexels.com/photo/passengers-in-a-ferry-18542927/)
- [People Boarding Ferry in Istanbul](https://www.pexels.com/photo/people-boarding-ferry-in-istanbul-17081934/)
