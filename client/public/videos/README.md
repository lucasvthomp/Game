# Marcamar hero video

`marcamar-hero-boat.mp4` is a compressed 720p copy of the free-to-use Pexels clip [Drone Shot of the Boats in the Beach](https://www.pexels.com/video/drone-shot-of-the-boats-in-the-beach-4279502/) by LUIS ADOLFO BURGOS. The file is encoded forward and then in reverse so its first and last scenes match for a smoother loop.

It is used as the muted, looping homepage hero background in `client/src/pages/Home.tsx`.
