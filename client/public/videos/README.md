# Marcamar homepage media

The homepage hero is a muted, non-looping panoramic ferry shot loaded directly from Pexels' HD CDN. It shows a passenger ferry moving through a working coastal harbor for approximately 50 seconds, so the footage stays sharp instead of being compressed into the repository's small binary limit.

- Hero source: [Aerial View of Ferry Boat](https://www.pexels.com/video/aerial-view-of-ferry-boat-5579142/) by Alan W
